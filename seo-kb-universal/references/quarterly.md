# quarterly：季檢（半天）

目標：全站內容 A–E 分級並執行更新 / 合併 / 汰舊；母表重新評分（季節係數）；蠶食稽核；競爭者與 SERP 變化。對應 02 §11、§13、14 §F 季稽核清單的內容與關鍵字列。首次在 setup 當天做，之後每 13 週。

## 步驟

1. 拉 90 天 vs 前 90 天，加去年同期：
   ```bash
   S="<SKILL_DIR>/scripts"; O=<專案>/seo-ops
   python3 $S/gsc_pull.py --site <資源> --sa <sa.json> [--country <國碼>] --days 90 --yoy --out $O/data
   python3 $S/kw_analyze.py $O/data/<日期>/gsc.json --config $O/config.json --master $O/keyword-master.csv --grade --sitemap <sitemap> --out $O/reports --append-log $O/action-log.csv
   ```
2. **分級**（報告第 9 節與 `reports/<日期>-grades.csv`，02 §13.1）：
   - A：排進下季每月的 20% 更新產能，曝光高者先。
   - B：每頁看 SERP 是否變了（新格式、新競爭者、AIO）；依新 SERP 重寫；補連結。
   - C：6–12 個月輕量更新，排到日曆尾。
   - D?：人工補兩個欄位：發佈日期（> 6 個月才算 D）、索引狀態（URL 檢查）。確定 D 的三選一：合併到相關頁（301）、改寫瞄準新意圖、刪除（410）。刪前確認外部連結與內部連結（02 §13.2）；一季刪的量分批，不要一次清掉大量頁面。
   - E：人工掃過時 / 違規（資訊錯、產品停售、政策變），立即處理。
   - 驗收：D 級比例 < 15%；上季更新過的頁 60 天後曝光 / 點擊有沒有動。
3. **母表重評分**（14 §F、02 §7、§11）：
   - 季節欄：Google Trends 5 年曲線重看；下季旺季字 S × 1.5 並排在旺季前 8–12 週；淡季字 × 0.5。在地季節事件（連假、開學、年終獎金、購物節）依目標市場整理，台灣見 24 章。
   - hub 完成度：每個 hub 已發佈 / 規劃篇數；< 50% 的 spoke × 1.3。
   - D 修正：核心主題的 SERP 重看一次，大站或官方佔滿就降 1–2 分。
   - 新站滿 6 個月：D 權重從平方改回一次方。
4. **蠶食稽核**（02 §12.2 第 5 點）：報告第 7 節全部過一遍，不只前 20；處理照 02 §12.3。
5. **SERP 與 AI 變化**（14 §F、08 章）：核心 hub 的主字各看一次 SERP，記錄 AIO、論壇區塊、影片是否新出現；GSC 的 Search Generative AI performance report 看 AI 曝光趨勢（只有曝光，13 §13.1.1）。資訊型主題被 AIO 覆蓋的，策略轉向可被引用的格式與交易 / 比較型（08 章、01 §8 R02）。
6. **競爭者矩陣**（01 章、14 §F）：3 個直接競爭者的新 hub、格式變化、流量估計；content gap 補進母表（02 §2 步驟 2 規範）。
7. **年比**（報告第 1 節 yoy）：點擊年比為負但季比持平 → 看是季節還是長期衰退（12 B3）。
8. 更新 `ops-plan.md`：下季 hub 優先順序、產能分配、汰舊批次；`ops_calendar.py schedule --weeks 13` 重產時程；`ops_calendar.py done quarterly --note "A n / B n / D n（刪 n 合併 n）"`。

## 對話輸出

- 分級統計表 + D 比例是否通過
- 最該先做的 3 件（通常是：曝光最高的 A 頁、衰退最多的 B 頁、一批 D 的處置）
- 下季季節字清單與發佈截止日（旺季 − 8 週）
- 要使用者決定的：汰舊是否執行、hub 優先序、是否開新 hub（→ research）

## 判讀提醒

- 90 天 vs 前 90 天會跨季節，年比才是分辨季節的依據（02 §11 驗收用 16 個月比較）。
- sitemap 零曝光頁可能是剛發佈或被 noindex，不是都 D；分級 CSV 的 D? 一定要人工補發佈日期。
- 刪除不是萬靈丹，Google 說單純刪舊內容不會自動提升排名（02 §13.1 為什麼）；重點是提升整體有用性。
- 核心更新期間不做季檢結論，等更新完成後以前後各 14 天比較（13 §13.9.1 最後一列）。
