## 3. 鐵律 32 條

違反任一條都曾造成真實專案的流量損失。每條附章節，細節與例外請到該章讀。本節經 Grok 對抗式審校（2026-11-03），過於絕對的條文已補上例外。

### 策略與內容

1. 每個「要爭取排名」的頁面都要能回答「這頁提供了別處沒有的什麼」；答不出來就不要發佈或 noindex。功能頁與法務頁（隱私、聯絡、登入）不受此限，依有無搜尋需求決定是否索引。（05 §9、11 §6）
2. AI 可以輔助產製，但每頁都要人工事實查核，範圍含標題、描述、結構化資料、alt；人工審閱不能單獨豁免 scaled content abuse，主要為佔排名而批量產頁仍屬違規。（07 §5.2、§9、11 §9）
3. 不用假作者、假頭像、假資歷；YMYL 內容必須有可查證的作者與來源。（05 §8、§11）
4. 同一個搜尋意圖只做一個頁面；意圖不同（資訊 / 比較 / 交易、不同對象）可以並存。發現蠶食先確認意圖是否真的相同，再選擇區隔、調整內鏈與 canonical，或合併後 301。（02 §12）
5. 標題不得誤導或與內文不符；Discover 內容政策一向限制誘餌式標題，2026-02 的 Discover 更新進一步強化。（07 §8、20 §20.7）
6. 內容更新要真的更新，不可只改日期。（05 §12、20 §20.5）

### 架構與技術

7. 重要頁面至少有一條可爬的內部連結，絕不可是孤兒頁；「距首頁 ≤ 3 次點擊」是風險指標而非 Google 門檻，深層頁有內鏈且在 sitemap 仍可被索引。（03 §5、§10）
8. 每個可索引 URL 只有一個版本：統一 www / 非 www、HTTPS、尾斜線、大小寫，其餘 301。（03 §2、04 §7）
9. canonical、sitemap、內部連結三者指向必須一致；hreflang 則分別指向各語系自己的 canonical，並做雙向回指與 x-default，不可全部指向同一語言。（04 §5、10 §2）
10. robots.txt 只擋「不想被爬」的，不用它來「移除索引」；要移除用 noindex 且允許爬取。（04 §2–§3）
11. sitemap 只放 200、可索引、canonical 的 URL；不放 noindex、轉址、404。（04 §4）
12. 永久搬遷用 301 / 308，暫時分流與維護用 302 / 307（誤用 301 可能被長期保留）；轉址鏈盡量不超過 2 跳，絕對禁止轉址迴圈。（04 §7）
13. 主要內容必須在伺服器端 HTML 或可被 Googlebot 渲染；不要依賴使用者互動後才載入的內容。（04 §10）
14. Core Web Vitals 以 CrUX 第 75 百分位為準：LCP ≤ 2.5 s、INP ≤ 200 ms、CLS ≤ 0.1。（04 §11）
15. 廣告位與嵌入內容一律預留尺寸，禁止推擠版面。（09 §6、15 §11）
16. 禁止依 IP 自動轉址到其他語言版本；用提示列讓使用者選。（10 §4）
17. 分面導覽的組合參數預設不可索引；只開放有搜尋需求的組合。（03 §8、19 §5）
18. 任何改版 / 搬遷都要先有 URL 對應表、再有 301、再上線；上線後 7 天內逐日看索引。（03 §13、14 §G）

### 政策與風險

19. 每季用垃圾政策清單自查整站，不只看 AI 內容與連結。（07 §4）
20. 第三方內容（聯盟、優惠券、贊助）不符合「呈現 / 品質 / 作者 / 獨特性」四面向就放獨立網域或 noindex。（07 §5.3、11 §11）
21. 過期網域只用於主題相關或全新有價值的網站；不借舊聲譽放無關內容。（07 §5.1、11 §12）
22. 不買連結、不用 PBN、不做以交換為主的連結方案；有金錢或物品對價的連結加 rel="sponsored"（nofollow 亦可接受），無對價的自然編輯引用不必加。（16 §4–§6）
23. 返回鍵必須能回到上一頁；每次新增腳本或換廣告商後重測。（07 §5.4）
24. 核心更新推出期間凍結投機性改版，但索引事故、安全問題與手動處置照修；結束後至少等 7 天（並計入 GSC 延遲）再分析；核心更新沒有重審機制。（07 §7）
25. 收到手動處置 48 小時內啟動修復，修完「全部」受影響內容再提交重審。（07 §6）

### 變現與監測

26. 申請 AdSense 前先過 14 §I 清單：原創內容、完整導覽、隱私政策、無「建設中」頁。（22 §1、§6）
27. 不自點廣告、不誘導或激勵點擊、不為製造廣告點擊而買量；付費導流只能導向內容，不得與廣告點擊或報酬綁定。無效流量是帳號層級風險。（09 §8）
28. 聯盟連結必須揭露，且揭露放在連結之前的可見位置。（09 §9）
29. 每週看 GSC 手動處置 / 安全性問題；每日看流量告警；Discover 與 Search 分開看。（13 §13.9、07 §8）
30. 任何流量驟降先排除追蹤問題，再走第 12 章的決策樹；不先改站。（12 決策樹）
31. 限制 AI 訓練只動 Google-Extended 等專用代稱，絕不 Disallow Googlebot；要退出 AI Overviews / AI Mode 用 GSC 的 Search generative AI 控制項，並把搜尋、Discover、AI 引用分開衡量。（08 §7、§10、15 §2）
32. 對歐洲經濟區、英國與瑞士流量使用 Google 認證的 CMP（第三方 CMP 須支援 TCF v2.3，2026-03-01 起強制）並正確送出 Consent Mode 訊號，否則 AdSense 收益與 GA4 衡量受限；美國各州依 GPP 訊號處理，其他市場依在地隱私法規另列。（22 §2.6、15 §14）
