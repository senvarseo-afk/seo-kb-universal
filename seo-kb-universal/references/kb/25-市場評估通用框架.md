# 25 市場評估通用框架

> 版本：1.0 ｜ 更新日期：2026-11-06 ｜ 適用：評估任何國家或語言市場

## 本章摘要

1. 新市場先過三道門：語言能否變現、內容與資料能否合法做、目標讀者找得到你。
2. 語言合規排第一。語言不在 AdSense 支援清單時，先改變現方式或語言結構，不要先做內容。
3. 不要用別國數字推估。每個市場都要查搜尋引擎、AI 功能、社群平台、變現與法規五件事。
4. 用小規模驗證取代長篇預測，兩到四週內拿到真實 SERP、社群和收益訊號。

## 1. 評估流程

| 步驟 | 要回答的問題 | 去哪裡查 |
|---|---|---|
| 1 語言 | 主要語言能跑廣告嗎？ | 22 章支援語言、§2 |
| 2 需求 | 目標讀者查什麼、用哪種語言查？ | 02 章、實際 SERP、當地論壇 |
| 3 競爭 | 前十名是誰？官方、媒體、論壇還是薄內容？ | 02 §1、在當地語言與地區設定下檢查 |
| 4 AI | AI Overviews 或 AI 模式有支援嗎？ | Google 官方支援頁、08 章 |
| 5 渠道 | 搜尋以外的讀者在哪裡？ | §4 |
| 6 變現 | 收益模型算得過來嗎？ | §5、09 章 |
| 7 法規 | 主題、廣告和個資有什麼限制？ | §6 |
| 8 驗證 | 最小實驗怎麼做？ | §7 |

**時效：** 市場資料變動快。報告中的每個數字都要寫來源與日期，超過 90 天的政策或平台資料要重查。

## 2. 語言與變現門檻

**規範：** 選語言前先查 AdSense 官方支援語言清單。Google 規定，頁面主要內容使用不支援語言時不得放置 Google 廣告代碼。

| 情況 | 做法 |
|---|---|
| 主要語言在清單內 | 繼續評估 |
| 主要語言不在清單內，但讀者也讀英文或其他支援語言 | 以支援語言做主內容 |
| 主要語言不在清單內，且讀者只讀該語言 | 改用直售、聯盟或其他廣告網，並先查對方語言政策 |
| 多語言站 | 語言分開成獨立 URL。廣告只放在支援語言的頁面，並確認主要內容判定（22 章） |

**常見錯誤：** 以為 AI Overviews 支援某語言，就代表 AdSense 也支援。兩份清單是分開的，要分別查。

## 3. 混語市場

混語是指讀者在同一句混用兩種語言，例如中英混用。

- **依搜尋行為決定：** 用真實 SERP 和 Search Console 查詢確認讀者用什麼語言搜尋，不要假設。
- **Google 看可見內文：** 語言判定看頁面內容，不看 `lang` 屬性。混語頁會歸到主要語言。
- **分開做關鍵字研究：** 純當地語、純英文與混語查詢可能對應不同 SERP 和 AI 回答。
- **不要機翻冒充在地：** 大量機翻低價值內容可能屬 scaled content abuse（07 §5.2）。
- **一頁一種主要語言：** 混語用在語氣和用詞，不要讓同頁出現兩份完整翻譯。
- **hreflang：** 混語沒有專屬代碼，用該頁主要語言。只連到真實存在的對應語言頁（10 章）。

## 4. 渠道盤點

每個市場填一次，來源要寫日期。

| 渠道 | 要查什麼 | 紀錄 |
|---|---|---|
| 搜尋 | Google、Bing 與在地引擎的導流占比 | 數值、日期 |
| 社群 | 主要平台、年齡分布、外連是否受限 | 平台、受眾 |
| 通訊 | 主要通訊軟體與社群功能 | 可否建名單 |
| 影音 | 長影片與短影音的主要平台 | 內容形式 |
| 論壇 | 當地問答、論壇與社團 | 版規、商業限制 |
| 自有 | 電子報、推播、App | 回訪能力 |

**風險：** 單一平台占比過高時要有備案。平台可能改演算法、限制外連，也可能被政府封鎖。

共通順序（社群主張）：先在當地社群驗證題目，再切成短內容，接著寫長文接搜尋與 Discover，最後收成電子報等自有渠道。11 §17 有各渠道評分，但那是社群主張，要在當地重新驗證。

## 5. 變現估算

**規範：** RPM 只用自家報表。沒有資料時，只做情境試算，並明確標示假設。

```text
月收入 = 月造訪 × 每次造訪頁數 ÷ 1000 × 頁面 RPM + 聯盟核准收入 + 其他收入
```

- 把流量依國家、裝置、主題和來源分開。不同區隔的 RPM 不能混用。
- 跑三種情境：保守、基準、樂觀。AI 摘要多的資訊型查詢要用較低 CTR（08 §2.2）。
- 付款前先確認收款方式、幣別、稅務資料與最低門檻（22 章）。
- 低 RPM 市場要看量和成本。內容、主機與審稿成本都要算進去。
- 導流賺差價的風險見 22 章，低品質流量可能造成無效流量。

## 6. 法規與平台風險

進入市場前至少查這些項目，並寫下來源：

- [ ] 廣告與業配揭露規定。
- [ ] 個資保護與 Cookie 規定。
- [ ] 博弈、金融、醫療、藥品、成人與政治內容限制。
- [ ] 比分、賽事轉播、媒體內容等資料與著作權限制。
- [ ] 平台封鎖、網路審查或內容下架紀錄。
- [ ] Google Ads 與 AdSense 在該國的政策例外。
- [ ] 公司、稅務與收款要求。

有疑慮的主題先諮詢當地律師。本框架不是法律意見。
