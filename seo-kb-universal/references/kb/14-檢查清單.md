> 版本：1.1 ｜ 更新日期：2026-11-05 ｜ 適用：所有 SEO 網站專案 ｜ 撰寫：Claude

## 本章摘要

1. 本章是可直接複製到專案文件 / 任務系統的檢查清單集合，共 10 份：上線前、上線後 7 天、每篇內容發佈前、每週、每月稽核、每季稽核、搬遷 / 改版 / 換網域、演算法更新後、申請廣告聯播網前、Google Ads 開戶與上線前。
2. 每一項都附「驗收工具」與「通過標準」；標準中的數值（CWV 門檻、聯播網門檻等）均已於 2026-11-03 查證並註明來源。
3. 清單只列「做什麼、怎麼驗」，原理與做法詳見對應章節（以「→ 章節」標示）。
4. 專案類型差異以【內容站】【電商】【本地】【SaaS / 企業】標記；未標記者通用。
5. 建議把清單匯入 Notion / Google Sheets，每次執行留存日期與執行者。

## 使用方式

- 格式：`- [ ] 項目 ｜ 工具 ｜ 通過標準`。
- 「必要」項目未通過不得進入下一步；「建議」項目可記錄為待辦。
- 本章引用的關鍵門檻（查閱 2026-11-03）：
  - Core Web Vitals「good」：LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1，以 75 百分位實際使用者資料計（來源：web.dev/articles/vitals、web.dev/articles/inp）。
  - TTFB 建議 ≤ 800ms（來源：web.dev/articles/ttfb）。
  - Journey by Mediavine：30 天內 ≥ 1,000 sessions 來自 Tier 1 國家（美、加、英、澳等）；Mediavine 主網路：年廣告收入 ≥ USD 5,000（來源：mediavine.com/requirements）。
  - Raptive：≥ 25,000 月瀏覽量；25,000–99,999 PV 需 ≥ 50% 流量來自美、英、加、紐、澳，≥ 100,000 PV 需 ≥ 40%（來源：raptive.com 公告 2025-10、help.raptive.com FAQ）。
  - AdSense：無官方流量門檻；需原創內容、年滿 18 歲、能存取網站 HTML、符合計畫政策；付款門檻 USD 100（來源：support.google.com/adsense/answer/9724、answer/1709871）。

## A. 上線前檢查清單

### A1. 技術（必要）→ 04、15 章

- [ ] staging 站已移除 `noindex` 與 robots 封鎖；正式站 `robots.txt` 可存取且未封鎖 CSS / JS ｜ `curl https://domain/robots.txt`、Search Console robots.txt 報表 ｜ 200，無 `Disallow: /`
- [ ] 全站 HTTPS，HTTP → HTTPS 301，無混合內容 ｜ `curl -I`、Chrome DevTools Security ｜ 100% 頁面安全鎖
- [ ] www / 非 www、尾斜線、大小寫只保留一個版本，其他 301 ｜ `curl -I` 四種組合 ｜ 皆 301 到唯一版本
- [ ] 每頁有自我參照 canonical，且與 sitemap、內部連結 URL 一致 ｜ Screaming Frog「Canonicals」 ｜ 0 筆不一致
- [ ] XML sitemap 只含 200、可索引、canonical URL；大於 50,000 筆則分檔 + 索引 sitemap ｜ Screaming Frog、Search Console Sitemaps ｜ 錯誤 0
- [ ] 404 頁回傳 404 狀態（非 soft 404）；自訂 404 有導覽 ｜ `curl -I https://domain/xxx-not-exist` ｜ HTTP 404
- [ ] 無重導向鏈（≥ 2 跳）與迴圈 ｜ Screaming Frog「Redirect chains」 ｜ 0
- [ ] 分頁、篩選、排序參數有明確處理（canonical / noindex / robots）→ 03、04 章 ｜ 爬取 + 抽查 ｜ 參數 URL 不進 sitemap、不被索引
- [ ] 【電商】faceted navigation 規則已定義並測試 → 19 章 ｜ 爬取 ｜ 爬取 URL 數 ≈ 預期可索引頁數
- [ ] 行動版與桌面版內容一致（mobile-first indexing） ｜ Search Console URL 檢查（Googlebot 智慧型手機） ｜ 內容、連結、結構化資料一致
- [ ] Core Web Vitals：實驗室測試主要模板 ｜ PageSpeed Insights、Lighthouse（行動） ｜ LCP ≤ 2.5s、INP ≤ 200ms（實驗室以 TBT 代理）、CLS ≤ 0.1
- [ ] TTFB ｜ WebPageTest（目標市場節點） ｜ ≤ 800ms
- [ ] 圖片有 `alt`、尺寸屬性（防 CLS）、現代格式（WebP / AVIF）、延遲載入（首屏除外） ｜ Screaming Frog「Images」 ｜ 缺 alt 0；首屏 LCP 圖片未 lazy-load
- [ ] 結構化資料無錯誤 → 06 章 ｜ Rich Results Test、Schema Markup Validator ｜ 錯誤 0；警告已評估
- [ ] `hreflang` 雙向 + x-default（多語言站）→ 10 章 ｜ Screaming Frog「Hreflang」 ｜ 無缺少回傳連結
- [ ] 內部連結：無孤立頁、點擊深度 ≤ 3、無指向 404 / 301 的內部連結 ｜ Screaming Frog「Crawl depth」「Inlinks」 ｜ 孤立頁 0；深度 > 3 的重要頁 0
- [ ] 安全標頭（HSTS、X-Content-Type-Options）與 CDN 快取規則 ｜ securityheaders.com、`curl -I` ｜ HSTS 存在
- [ ] 網站可被 Googlebot 渲染（JS 站） ｜ URL 檢查工具「查看已檢索網頁」 ｜ 主要內容在渲染後 HTML 中
- [ ] favicon 符合 Google 規格（至少 48×48 倍數、支援格式） ｜ 手動 ｜ 存在且可存取
- [ ] 每日自動備份已設定 ｜ 主機後台 ｜ 可還原測試通過

### A2. 內容（必要）→ 05、06 章

- [ ] 上線時至少 10–30 篇完整內容（非草稿） ｜ CMS ｜ ≥ 10
- [ ] 每個 hub 至少有樞紐頁 + 3 篇 spoke 並互連 → 02 章 ｜ 主題地圖 ｜ 100% hub 有樞紐頁
- [ ] 所有頁面 title 唯一、≤ 60 字元（英文約 580px）、含主關鍵字 ｜ Screaming Frog「Page Titles」 ｜ 重複 0、缺少 0
- [ ] 所有頁面 meta description 唯一（可自動產生但不可空白） ｜ Screaming Frog ｜ 重複 0
- [ ] 每頁一個 H1，標題層級不跳級 ｜ Screaming Frog「H1」 ｜ 缺少 / 多個 0
- [ ] 關於我們、聯絡、隱私權政策、免責聲明、編輯政策 / 作者頁已建立 ｜ 手動 ｜ 全部存在且在頁尾可達
- [ ] 作者頁含真實姓名、資歷、照片、社群連結（YMYL 必要）→ 07 章 ｜ 手動 ｜ 存在
- [ ] 無佔位文字（Lorem ipsum）、無空分類 / 標籤頁被索引 ｜ `site:` 搜尋 + 爬取 ｜ 0
- [ ] 【電商】產品頁有價格、庫存、Product 結構化資料 → 19 章 ｜ Rich Results Test ｜ 通過
- [ ] 【本地】NAP（名稱、地址、電話）全站一致並與 Google 商家檔案相同 → 17 章 ｜ 手動 ｜ 一致

- [ ] GA4 事件：外連點擊、捲動、搜尋、表單 / 購買（依類型） ｜ DebugView ｜ 事件觸發
