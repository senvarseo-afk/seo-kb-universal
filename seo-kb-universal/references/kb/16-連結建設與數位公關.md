# 16 連結建設與數位公關

> 版本：1.0 ｜ 更新日期：2026-11-03 ｜ 適用：所有 SEO 網站專案 ｜ 撰寫：Claude

## 本章摘要

1. 外部連結仍是 Google 的排名訊號之一，但 Google 自 2023 年起公開表示「連結不在前三大訊號」；連結的作用是「發現 + 權威 + 實體驗證」，不是流量站的唯一槓桿。
2. 連結品質 = 相關性 × 來源權威 × 真實流量 × 位置 × 錨文字自然度 × 屬性；一條相關、有流量的編輯型連結勝過一百條目錄 / 評論區連結。
3. 可持續的白帽方法：數位公關（原創數據、調查、工具）、資源頁、失效連結、品牌提及回收、社群/論壇參與；客座文章與 HARO 類平台在 2024–2026 年已大幅變質，須嚴格篩選。
4. Google 的 link spam 政策明確：買賣連結、過度交換、PBN、自動化、要求合約連結、優化錨文字的贊助/客座文章都是違規；付費與聯盟連結必須 `rel="sponsored"`（或 `nofollow`）。
5. Google 現行立場：絕大多數網站不需要 disavow；只有「大量垃圾連結已造成或可能造成手動處置」才用。負面 SEO 多數情況由 SpamBrain 自動忽略。

## 1. 外部連結如何影響排名（現況）

**Google 的公開說法（截至 2026-11-03）**：
- Google〈How Search works〉與〈Link best practices〉文件：連結是 Google「發現新頁面」與「判斷頁面是否值得信賴、與主題相關」的方式之一；錨文字幫助 Google 理解被連頁面主題（來源：Google Search Central〈Link best practices for Google〉，查閱 2026-11-03）。
- 2023-09 Gary Illyes 於 PubCon：連結「不是前三大排名訊號，而且已經有一段時間不是了」；並表示「沒有普遍適用的前三名，每個查詢、每個網站不同」。他同時強調連結仍然重要，只是不是最重要（來源：Search Engine Land 報導，2023-09；查閱 2026-11-03）。
- 2022-12 的 link spam update 起，Google 以 SpamBrain 自動「中和（neutralize）」不自然連結，包含「買的連結」與「用來傳遞連結的網站」，使其不產生效果，而非一律懲罰（來源：Google Search Central Blog〈December 2022 link spam update〉，查閱 2026-11-03）。
- 2024-05 外流的 Google 內部文件（非官方確認）顯示連結仍依來源品質分層處理、首頁權重、連結存在時間等屬性；僅作背景參考，不據以制定規範。

**對專案的實際意義**：
- 連結的三個真實作用：(1) 發現與抓取（新站、新頁面）；(2) 站級信任/權威（影響核心更新中的站級評估）；(3) 實體驗證（品牌、作者被第三方提及，支撐 E-E-A-T 與知識圖）。
- 內容站競爭「資訊型查詢」時，前 10 名常見零外鏈頁面；內容品質與主題覆蓋（詳見 02、05）的槓桿比連結大。
- 商業型查詢（best X、評論、交易）與高競爭 YMYL：連結與品牌訊號差異明顯，仍需投入。
- 新站：前 6 個月的少量真實連結對「脫離沙盒式低信任」有明顯幫助（內部觀察，非 Google 說法）。
- 連結的邊際效益遞減：從 0 → 20 個相關網域的效果，遠大於 200 → 220。

## 2. 連結品質評估框架

**規範**：每條潛在或既有連結以下表六維度評分（各 0–2 分），總分 ≥ 8 才列為「值得取得 / 保留」；任何一項為「紅線」即不取得。

| 維度 | 2 分 | 1 分 | 0 分 | 紅線 |
|---|---|---|---|---|
| 相關性 | 來源頁與連結上下文都與本站主題直接相關 | 站相關、頁不相關（或相反） | 完全無關 | 賭博、成人、藥品等與本站無關的高風險主題 |
| 來源權威 | 真實媒體、政府、學術、業界公認站；Ahrefs DR / Moz DA 僅作粗篩，不是標準 | 中型利基站、有真實編輯 | 無編輯、無關於頁 | 已知 PBN、連結農場、被 Google 除名 |
| 真實流量 | Ahrefs / Semrush 估計自然流量 ≥ 1,000/月且主題相關的流量頁 | 100–1,000 | < 100 | 流量全來自品牌外的垃圾查詢 |
| 位置 | 正文內、靠前、被編輯自然引用 | 正文末、作者簡介 | 側欄、頁尾、評論、站點範圍 | 隱藏連結、CSS 隱藏、1px |
| 錨文字 | 品牌、URL、自然描述句 | 部分比對（「目標國簽證指南」） | 精準比對商業關鍵字 | 與頁面無關的關鍵字 |
| 屬性與可抓取 | `<a href>` 可抓取、無 rel 限制 | `nofollow` / `ugc` 但有真實流量與曝光價值 | JS 連結不可抓取、被 robots 封鎖 | 重導向經過追蹤網域的連結偽裝 |

補充判準：
- 外鏈/內容比：來源站每篇都有 5+ 外部連結指向不同商業站 → 連結農場徵兆。
- 外鏈主題雜亂（同一站連到貸款、賭場、旅遊、CBD）→ 賣連結站，即使 DR 高也 0 分。
- 「Write for us」「Sponsored post」頁面存在 → 來源屬於 Google 2024-03 site reputation abuse / link spam 風險圈。
- 連結指向的目標：首頁 vs. 深層頁。深層頁（文章）的編輯型連結對該主題群排名幫助更直接。

**驗收方式**：每月以 Ahrefs「Referring domains」新增清單逐條打分；季度統計「≥ 8 分連結」占比，目標 ≥ 60%。

**常見錯誤**：只看 DR/DA；把 `nofollow` 一律視為零價值（品牌提及、流量、後續被引用的價值仍在）；為了相關性接受賣連結站。

## 3. 白帽方法詳解

### 3.1 數位公關（Digital PR）

**規範**：每季至少一個「可被報導的資產」（原創數據、調查、排名、工具），搭配針對性媒體名單發布。

**為什麼**：編輯型媒體連結是 Google 最明確「不會中和」的連結類型；媒體報導同時產生品牌搜尋與提及，是 E-E-A-T 與實體訊號的來源。

**怎麼做**：
1. 選題：與本站主題交集、媒體關心的角度（在地、時事、數字、比較、意外）。範例（流量站）：「分析 5,000 筆台灣旅客簽證申請時程」「東南亞 6 國 eSIM 價格指數」。
2. 資料來源：自有數據（GSC、讀者問卷、工具使用紀錄）、公開數據二次分析（政府開放資料、World Bank、各國移民局統計）、小規模調查（n ≥ 300，用 SurveyMonkey / Google Forms + 社群投放）。
3. 產出：專題頁（含方法論、原始資料下載、`Dataset` 標記，詳見 06）+ 1–3 張可嵌入圖表（附嵌入碼、要求署名連結）+ 新聞稿（300 字、3 個可引用數字、1 句專家評論）。
4. 名單：Muck Rack / Prowly / 手動整理；每家媒體找「寫過類似主題」的記者，個別化 pitch（主旨 ≤ 10 字、正文 ≤ 150 字、數字先行）。
5. 時機：配合新聞週期（開學季、連假前、政策生效前）。
6. 追蹤：媒體提及（Google Alerts、Brand24、Ahrefs Alerts）；未附連結的提及做「提及回收」（第 3.6 節）。

**驗收方式**：每個資產記錄「觸及媒體數 / 報導數 / 含連結數 / 連結評分」；目標每個資產 ≥ 5 個 ≥ 8 分連結（內部基準）。

**常見錯誤**：資料沒有新聞角度（「我們統計了網站流量」）；pitch 群發；沒有可嵌入圖表；專題頁上線後不更新。

### 3.2 原創資料研究 / 調查

與 3.1 同源，差別在資產本身的長期價值：年度化（「2026 版」「2027 版」）讓同一 URL 累積連結；提供「可引用的單一數字」（記者引用時只需一句話）；在頁面提供「如何引用」區塊（含建議引用文字與連結）。多語站可將同一研究翻譯成各市場版本，各自向當地媒體發布（第 11 節）。

### 3.3 工具 / 計算機

**規範**：每個主題群至少一個免費工具（簽證天數計算、費用換算、比較表產生器、checklist 產生器）。

**為什麼**：工具被引用時幾乎都是編輯型、正文內連結；工具頁本身也是 information gain 的最強形式（詳見 05 第 13.5 節）。

**怎麼做**：選「使用者需要重複計算」的問題；工具結果可分享（URL 帶參數）；提供嵌入版本（iframe + 署名連結，署名連結用 `nofollow` 以符合 Google 對 widget 連結的規範——見第 6 節）；主動向寫過該主題的部落格 / 論壇推薦。

### 3.4 資源頁連結（Resource page link building）

搜尋：`intitle:"resources" OR inurl:resources "簽證"`、`"useful links" 簽證`、`.edu.tw "links"`。只投遞到真實維護的資源頁（最近 12 個月有更新）；信件說明你的頁面補了哪個缺口；成功率 5–10% 為正常。

### 3.5 失效連結（Broken link building）

Ahrefs「Best by links」→ 競品 404 頁 → 找出連到它的站 → 提供你的替代頁。或 Check My Links 擴充掃資源頁。寫信要具體指出失效 URL 與替代頁；成功率 5–15%。

### 3.6 品牌提及回收（Unlinked mentions）

Ahrefs Content Explorer / Brand24 搜尋品牌名、作者名、工具名、獨特數據，篩「未連結」；向作者請求加連結（提供精準 URL）。成功率高（20–40%），成本最低；每月例行。

### 3.7 客座文章（Guest posting）的現況與風險

**現況（2026-11）**：
- Google 自 2017 年即警告「大規模以連結為目的的客座文章」違規；2024-03 的 link spam 政策明列「贊助文章、客座文章或新聞稿中含傳遞排名的連結或優化錨文字」為範例；site reputation abuse 政策（2024-05 起執行、2024-11 澄清第一方參與不豁免、2026-08 EEA 執行方式調整）讓接受大量外部客座文章的媒體面臨處置，許多主流媒體已關閉投稿或強制 `nofollow`/`sponsored`。
- 市場上「guest post 代寫 + 保證 dofollow」服務 = 付費連結，屬違規。

**可接受的形式**：真正的專欄 / 專家投稿（作者署名、內容是為該媒體讀者寫的、連結是自然引用、數量少）；視為「品牌與作者曝光」而非連結來源；連結被 `nofollow` 也接受。

**風險判準**：對方有公開價目 / 「write for us」頁且主題雜 / 要求固定錨文字 → 不做。

### 3.8 HARO 類平台現況

- HARO 母公司改名 Connectively 後於 2024-12-09 關閉；HARO 品牌於 2025-04 由 Featured.com 取得。現況（featured.com/pricing，查閱 2026-11-03）：HARO 不再是獨立產品，而是 Featured 平台「Journalist Requests」來源之一（「Respond to journalist queries from HARO, LinkedIn, and more」）；Featured 採 freemium，個人方案 Free USD 0、Lite 39／月（年繳 29）、Pro 99（年繳 79）、Pro+ 299（年繳 239），Team Lite／Pro／Pro+ 199／499／1,499／月，Enterprise 另議；各方案功能相同，差別在 AI 用量與每週 pitch 上限。
- 替代平台：Source of Sources（SOS，HARO 創辦人 Peter Shankman 創立，免費電子報）、Qwoted（記者密度高）、Featured.com、Help a B2B Writer、SourceBottle（澳洲/紐西蘭為主）。
- 現況風險：大量「記者」其實是內容站用來換取免費內容與連結的來源；AI 生成的回覆氾濫導致採用率下降。
- 做法：只回覆真實媒體（查域名、記者社群帳號）；回覆 ≤ 150 字、含可引用句與具體經驗；每週固定 2 小時；追蹤「回覆數 / 採用數 / 含連結數」，採用率低於 5% 持續 3 個月就停止。
- 來源：各平台公告與 Search Engine Land / PR 業界報導（2024-12 至 2025-04），查閱 2026-11-03。

### 3.9 社群與論壇

Reddit、Quora、Facebook 社團、Dcard、PTT、Kaskus（印）、Voz / Webtretho（越）等的連結多為 `nofollow` / `ugc`，但：(1) Google 2024 年起大量展示「討論與論壇」結果，Reddit 等本身排名高，帶來推薦流量；(2) 真實參與產生的提及是品牌訊號。規範：只在真正回答問題時附連結；帳號有歷史與非連結貢獻；不建立多帳號；不自問自答。

### 3.10 品牌提及（無連結）

Google 未確認「無連結提及」是排名訊號，但實體理解（知識圖、AI 回答中的品牌辨識）明顯受第三方提及影響。做法：媒體訪談、Podcast 來賓、業界清單（「台灣東南亞旅遊 KOL 20 選」）、Wikidata / 維基百科條目（符合關注度時）、社群一致的品牌名與 `sameAs`（詳見 06）。

### 3.11 內容本身作為連結誘餌

被引用最多的格式（內部觀察 + Ahrefs 研究通則）：原創統計頁、「X 的完整指南」長青頁、對照表、免費模板 / checklist、術語表、年度報告、爭議性但有據的觀點文。流量站每個主題群規劃 1 個「連結資產」頁，其餘頁面透過內部連結分配權重（詳見 03）。

## 4. Link spam 政策與 SpamBrain

**Google〈Spam policies〉link spam 段落（查閱 2026-11-03）**：「主要為了操控排名而建立指向或來自網站的連結」即 link spam。範例：
- 買賣連結換取排名（金錢、商品、服務、免費產品換連結或含連結的文章）。
- 過度連結交換或純為交叉連結建立的夥伴頁。
- 自動程式或服務建立連結。
- 在服務條款或合約中要求連結且不讓對方自行加 rel 屬性。
- 傳遞排名的文字廣告 / 文字連結。
- 含傳遞排名連結或優化錨文字的廣編、贊助文章、客座文章、新聞稿。
- 低品質目錄 / 書籤站連結。
- 散布到多站的 widget、頁尾、模板中的優化連結。
- 論壇留言 / 簽名檔中的關鍵字優化連結。
- 主要為了操控連結與排名而建立的低價值內容。

**不違規**：廣告或贊助連結加上 `rel="nofollow"` 或 `rel="sponsored"`。

**SpamBrain**：Google 的 AI 垃圾偵測系統（2018 起），2022-12 link spam update 起用於偵測「買連結的站」與「用來傳連結的站」，並使這些連結失效（中和）；Google 表示這會讓依賴此類連結的排名下降，但不是手動處置。2026-04 Google 更新文件：可能依垃圾檢舉（spam report）採取手動處置。

**實務推論**：
- 大多數低品質連結被忽略（不加分也不扣分）；大規模、明顯的購買模式會讓整批連結失效，排名回落到「沒有這些連結」的水準。
- 手動處置「不自然連結（指向你的網站）」仍存在，通常針對明顯、持續、大規模的模式；「不自然連結（來自你的網站）」針對賣連結的站。
- 流量站的真實風險：(1) 買來的連結失效後流量回落；(2) 被捲入 PBN 網路時同網路被整批中和；(3) 賣連結（接贊助文卻不加 `sponsored`）導致本站被視為連結來源垃圾。

## 5. 付費連結、連結交換、PBN 的風險

| 做法 | Google 判定 | 現實風險（2026） | 替代 |
|---|---|---|---|
| 付費 dofollow 連結（含「guest post 套餐」） | 違規 | 最常見結果是被中和（白花錢）；大規模會手動處置；賣方站被除名時連結消失 | 數位公關、工具、提及回收 |
| 聯盟 / 贊助內容要求 dofollow | 違規 | 同上；且使合作媒體冒 site reputation abuse 風險 | 要求 `sponsored` 並以曝光價值評估 |
| 互惠交換（我連你、你連我） | 「過度」才違規 | 少量、相關、自然的互連無妨；系統化交換（表格管理、數十站）會被偵測 | 內容合作、共同研究 |
| 三方交換（A→B→C→A） | 違規（意圖操控） | 同交換 | — |
| PBN（自建或租用過期域名網路） | 違規；同時觸及 expired domain abuse 政策 | 網路一旦被辨識整批中和；租用 PBN 的連結常在續約停止後消失；曝光後流量站主站連坐 | — |
| 過期域名 301 到主站 | 高風險 | 2024-03 expired domain abuse 政策；主題不符的 301 被忽略或視為操控 | 只在品牌 / 主題一致、承接真實內容時使用 |
| 低價目錄 / 書籤 / Web 2.0 | 違規範例 | 無效；大量時是負面模式訊號 | 僅提交真正有人用的業界目錄（含 nofollow 亦可） |
| 評論 / 論壇簽名自動化 | 違規 | 無效 | 真實參與 |
| 「Niche edit」（付費插入既有文章） | 付費連結 | 同付費連結；常見於已被中和的站 | 提及回收（免費、合規） |

**成本—風險判斷**：流量站變現依賴 AdSense / 聯盟計畫，任何手動處置或大規模中和都直接打擊收入；因此本知識庫規範：**不購買傳遞排名的連結、不參與 PBN、不系統化交換**。若接手的既有專案已有此類連結，依第 8、10 節處理。

## 6. rel=nofollow / sponsored / ugc 的正確用法

**規範**（依 Google〈Qualify your outbound links〉，查閱 2026-11-03）：

| 連結類型 | 必用屬性 | 說明 |
|---|---|---|
| 廣告、付費置入、贊助內容中的連結 | `rel="sponsored"`（`nofollow` 仍可接受） | 包含聯盟連結（Google 在聯盟計畫指南中要求適當的連結處理） |
| 使用者產生內容（評論、論壇貼文、會員簡介） | `rel="ugc"` | 長期貢獻優質內容的會員可移除 |
| 不想背書、不想 Google 從本站抓取的連結 | `rel="nofollow"` | 「其他值不適用時」使用 |
| 本站內部不想抓取的頁面 | 不要用 nofollow；用 robots.txt 或 noindex | Google 建議 |
| 一般編輯型外部連結（引用來源、推薦） | 不加 rel | 對外連結到權威來源是正常且有益的 |
| 嵌入式 widget / 徽章中的署名連結 | `nofollow` 或 `sponsored` | 避免散布型優化連結 |
| 新聞稿中的連結 | `nofollow` | Google 範例明列 |

- 可組合：`rel="sponsored nofollow"`、`rel="ugc nofollow"`（空格或逗號分隔）。
- Google 自 2019-09 起把這些屬性視為「提示（hint）」而非指令（2020-03 起用於抓取與索引）；Google 文件現在說這類連結「通常不會被追蹤」。實務上仍假設它們不傳遞排名。
- 聯盟連結實作：直接 `<a href="https://partner.example/?aff=123" rel="sponsored">`；若經本站跳轉頁（`/go/product/`），跳轉頁用 robots.txt 封鎖或 `noindex`，`<a>` 仍加 `sponsored`。
- 不要全站外部連結一律 nofollow：會讓引用來源的信任訊號消失，且是「怕被連坐」的過度反應。
- 入站連結：你無法控制他站屬性；一條有真實流量的 nofollow 連結仍值得取得。

**驗收方式**：Screaming Frog「Outlinks」篩選外部連結，檢查聯盟網域是否 100% 帶 `sponsored`；AdSense / 聯盟稽核時這也是揭露合規的一部分（詳見 09）。

**常見錯誤**：聯盟連結無屬性；贊助文只在文末寫「本文為合作文」但連結 dofollow；UGC 區塊未加 `ugc` 導致被濫發垃圾連結（Google 2026-10 更新了〈防止 UGC 垃圾〉指南：封鎖連結分享內容的索引、在 GSC 監測）。

## 7. 錨文字分布與連結速度

**錨文字（入站）**

**規範**：自然分布，不設定「精準比對 X%」目標；若精準比對商業關鍵字占比 > 10–15% 且集中在近期，視為風險（內部基準，非 Google 數字）。

| 類型 | 自然來源占比（健康站常見） | 範例 |
|---|---|---|
| 品牌 / 網址 | 40–60% | 「Example 旅遊指南」、example.com |
| 自然描述 / 整句 | 20–35% | 「這篇整理了延簽流程」 |
| 通用 | 5–15% | 「這裡」「來源」 |
| 部分比對 | 5–15% | 「目標國簽證的整理」 |
| 精準比對 | < 10% | 「目標國簽證」 |

你能控制的只有：提及回收時提供的建議錨文字（用品牌或自然句）、工具嵌入碼的署名文字、內部連結（詳見 03）。

**連結速度（link velocity）**

- Google 沒有公開「速度閾值」；不自然的是「與站的實際曝光不成比例的突增」（例如月增 500 個低品質網域而無任何新聞事件）。
- 數位公關造成的短期暴增（有真實報導）是正常的；Google 可分辨。
- 新站建議節奏：前 3 個月以內容與少量提及為主；每月新增相關網域 5–20 個屬於自然範圍（內部基準）。
- 監測：Ahrefs「New referring domains」月趨勢 + 品質評分；暴增且低分 → 第 9 節。

## 8. Disavow 的使用時機（Google 現行立場）

**Google〈Disavow links to your site〉（查閱 2026-11-03）**：
- 「大多數網站不需要使用此工具」；Google「通常能自行判斷哪些連結可信」。
- 只有在「你有相當數量的垃圾、人為或低品質連結指向你的網站，且這些連結已造成或很可能造成手動處置」時才使用；先盡量請對方移除。
- 格式：每行一個 URL 或 `domain:example.com`；UTF-8 / ASCII `.txt`；`#` 註解；不支援子路徑；單檔 ≤ 100,000 行、≤ 2MB；URL ≤ 2,048 字元；每個資源一份清單，上傳即取代；http / https 需各自上傳；不支援「網域資源（Domain property）」——需用網址前綴資源；生效需「幾週」；取消也需幾週。

**本知識庫規範**：

| 情況 | 是否 disavow |
|---|---|
| GSC 有「不自然連結」手動處置 | 是：先請求移除、記錄，再 disavow 剩餘，提交重審 |
| 曾大量購買連結（自己或前手），尚無手動處置，但核心更新後下滑 | 可考慮：只列明確購買的網域；不要為了「清乾淨」亂列 |
| 競品 / 不明來源的垃圾連結暴增（負面 SEO），無手動處置 | 否（預設）：Google 會忽略；只有模式極端（數萬個、含違法主題錨文字）且持續時再 disavow 網域層級 |
| 工具標示「toxic」但來源是真實小站 | 否：第三方毒性分數不是 Google 標準 |
| 流量下降但連結檔無明顯異常 | 否：原因在內容/技術/演算法（詳見 07、12） |

**操作步驟**（需要時）：
1. 匯出 GSC「連結」報表 + Ahrefs / Semrush backlinks（合併去重）。
2. 以第 2 節框架 + 「明確購買 / PBN 特徵」標記；只列「確定為人為操控」的網域。
3. 用 `domain:` 層級，不逐 URL。
4. 保留檔案版本與日期；重審請求中附移除努力紀錄（寄信截圖、回覆）。
5. 上傳後持續 4–8 週監測；不要反覆增刪。

**常見錯誤**：把所有 nofollow / 低 DR 連結全部 disavow（可能移除真正有效的連結）；上傳到網域資源（不支援）；當成「排名下跌萬靈丹」。

## 9. 負面 SEO 判讀

**規範**：發現異常連結時先判讀「是否造成實際影響」，預設不行動、只記錄與監測；只有「同時出現手動處置或可歸因的排名異常」才進入 disavow 流程。

**判讀表**：

| 觀察 | 較可能是 | 行動 |
|---|---|---|
| 突增數千個來自俄/中/越等語言垃圾站、錨文字為賭博/成人/藥品 | 自動化垃圾（可能是競品或機器人隨機掃射） | 記錄；監測排名；通常不需 disavow |
| 突增來自「scraper」站複製你內容並連回 | 抓取站（非攻擊） | 無需處理；若排名被取代則 DMCA |
| 突增數百個 PBN 式文章頁、錨文字精準比對你的主要關鍵字 | 針對性負面 SEO | 監測 4 週；若排名明顯下滑且 GSC 出現手動處置 → disavow 網域 |
| 本站被他站以 canonical / hreflang 指向（罕見） | 技術型攻擊 | 檢查 GSC「網頁索引」；通常 Google 會忽略 |
| 大量 Google 垃圾檢舉導致手動處置？ | Google 2026-04 文件：可依檢舉採取手動處置，但仍基於實際違規 | 若本站無違規，重審說明即可 |
| 排名下滑但連結沒異常 | 不是負面 SEO | 轉向內容 / 技術 / 演算法排查（詳見 12） |

**為什麼**：Google 長期公開立場是「負面 SEO 極少有效，系統會忽略垃圾連結」；SpamBrain 的中和機制針對的是「受益方」模式。過度反應（大量 disavow）反而可能傷害自己。

**驗收方式**：建立「異常連結事件日誌」（日期、數量、特徵、當時排名、4 週後排名、是否處理）；每季回顧確認「不處理」是否曾造成損失，用以校正閾值。

## 10. 連結稽核與監測流程

**每月（30 分鐘）**
1. Ahrefs / Semrush：新增 referring domains 清單 → 第 2 節評分 → 記錄 ≥ 8 分數量與占比。
2. 失去的連結（Lost）：原因（頁面移除、改 nofollow、站關閉）；高分連結流失時聯絡對方或檢查目標頁是否 404。
3. GSC「連結」報表：外部連結最多的頁面 / 錨文字前 20 → 錨文字是否異常集中。
4. 提及回收：Brand24 / Ahrefs Alerts 未連結提及 → 寄信。
5. 本站外部連結稽核：Screaming Frog 聯盟與贊助連結屬性合規。

**每季（半天）**
1. 完整連結檔健康報告：referring domains 總數、相關網域占比、錨文字分布、連到首頁 vs. 深層頁比例、`nofollow` 占比、前 10 大來源品質。
2. 競品差距分析（Ahrefs Link Intersect）：連到 ≥ 2 個競品但沒連到我們的站 → 名單。
3. 連結資產盤點：哪些頁面吸引最多連結 → 更新、擴充、年度化。
4. 內部連結分配：高外鏈頁是否有內部連結到需要權重的商業頁（詳見 03）。
5. 異常事件日誌回顧（第 9 節）。

**每年**
- 連結策略檢討：各方法的「投入時數 / 取得 ≥ 8 分連結數」，淘汰效率最低者。
- 接手舊站 / 併購網域前：完整連結檔盡職調查（購買痕跡、PBN、手動處置紀錄、expired domain 歷史——Wayback Machine 看主題是否一致）。

**工具最低配置**：GSC（免費，必要）、Ahrefs 或 Semrush（擇一）、Google Alerts（免費）+ Brand24 / Mention（可選）、Screaming Frog。工具細節詳見 13。

## 11. 多語言 / 新興市場（東南亞）的連結來源特點

以下為業界觀察與實務經驗整理（非 Google 官方），標註為內部判斷；各市場實際狀況需在專案啟動時重新驗證。

**共通特點**
- 網路生態 Facebook 中心化：大量討論在 FB 社團與粉專，連結幾乎全是 `nofollow` 且不可抓取；價值在推薦流量與品牌提及，不在連結權重。
- 媒體連結政策：主流媒體（越南 VnExpress、Tuoi Tre；印尼 Kompas、Detik）多對外部連結加 nofollow 或不加連結；取得方式是真實新聞價值（在地數據、在地角度）。
- 「Guest post 市場」高度商品化：大量 DR 30–60 的英文「新加坡 / 馬來西亞」站公開賣連結，主題雜（賭場、貸款、CBD 混雜），是 SpamBrain 最容易辨識的連結圈；避開。
- 賭博 / 博弈產業的連結需求扭曲整個市場：許多在地部落格、論壇、甚至新聞站有被植入賭博連結的紀錄；評估來源時檢查其外鏈主題（Ahrefs「Linked domains」）。
- 政府（.gov.vn、.go.id）與大學（.edu.vn、.ac.id）網域的資源頁與公告頁仍是高信任來源；取得方式是提供對公眾有用的資源（翻譯指南、工具）並正式聯繫。
- 多語言：各語言版本頁面要分別取得該語言的連結（越南文頁需越南站連結），Google 對 hreflang 版本的權威評估是頁面層級的（詳見 10）；用同一份研究翻譯成當地版發布，是最經濟的做法。

**越南**
- 論壇文化仍強（Voz、Webtretho、Tinhte）；越南文內容必要；媒體連結嚴格。
- PBN 與買賣連結市場極大（越南文 SEO 社群以此為主流），來源篩選要特別嚴格。

**印尼**
- Kaskus、Quora Indonesia；大量「jasa backlink」服務；印尼文內容必要；Kompas / Detik 等媒體有 UGC 專區（Kompasiana）但連結為 nofollow / ugc。

**馬來西亞 / 新加坡**
- 英語市場，媒體連結相對可得（Mothership、Vulcan Post、SAYS）；新加坡政府與機構資源頁品質高。

**台灣 / 華語**
- PTT、Dcard（nofollow，但推薦流量與品牌訊號強）；媒體（ETtoday、聯合、自由、關鍵評論網）有專欄投稿管道（多 nofollow）；痞客邦等部落格平台連結價值低；產業公協會、政府開放資料平台的資源頁可取得。

**操作建議**
1. 每個市場建立「可信來源白名單」（媒體、政府、大學、真實社群、真實部落客）與「黑名單」（公開賣連結、賭博外鏈站）。
2. 在地化資產優先：當地語言的數據報告 + 當地媒體名單。
3. 以推薦流量與品牌搜尋量作為東南亞連結工作的主要 KPI，連結數為次要。

## 13. 外部連結 → 狀況解法表

| 症狀 | 可能原因 | 診斷步驟 | 解法 | 預防 |
|---|---|---|---|---|
| GSC 出現「不自然連結（指向你的網站）」手動處置 | 明顯購買 / PBN / 大規模交換 | 讀取範例 URL；匯出所有連結並標記人為連結 | 請求移除 → disavow 剩餘 → 重審請求附紀錄；預期 2–6 週 | 不購買；接手專案先盡職調查 |
| GSC 出現「不自然連結（來自你的網站）」 | 本站賣連結 / 贊助文 dofollow / 被植入連結 | Screaming Frog 全站外部連結；查是否被駭植入 | 加 `sponsored`/`nofollow` 或移除；清除惡意植入；重審 | 外部連結稽核每月 |
| 買的連結上線但排名無變化 | 被 SpamBrain 中和；來源無價值 | 檢查來源外鏈主題、是否被索引 | 停止；轉白帽 | 第 5 節 |
| 排名在核心更新後下滑，連結檔有大量低品質 | 站級信任受影響（連結只是其中一環） | 區分內容問題（詳見 05、07）與連結問題；看下滑是否集中在靠購買連結撐起的頁 | 以內容修正為主；明確購買者可 disavow | — |

## 14. 本章檢查清單

**策略與資產**
- [ ] 每個主題群有 1 個連結資產（數據頁 / 工具 / 完整指南）
- [ ] 每季 1 個可報導的數位公關資產
- [ ] 各市場媒體 / 來源白名單與黑名單已建立

**合規**
- [ ] 不購買傳遞排名的連結、不參與 PBN、不系統化交換
- [ ] 所有聯盟 / 贊助 / 廣告連結 `rel="sponsored"`（或 `nofollow`）
- [ ] UGC 區塊 `rel="ugc"`，且有垃圾防護
- [ ] 贊助內容頁有可見揭露（詳見 09）
- [ ] 嵌入碼署名連結用品牌錨文字 + `nofollow`

**監測**
- [ ] 每月：新增 / 流失連結評分、錨文字分布、提及回收、本站外部連結稽核
- [ ] 每季：連結檔健康報告、競品差距、連結資產更新、事件日誌回顧
- [ ] GSC 手動處置報表每週檢視
- [ ] 異常連結事件日誌維護；預設不 disavow

**Disavow（僅需要時）**
- [ ] 符合「大量人為連結 + 已有 / 可能手動處置」條件
- [ ] 已先嘗試移除並留存紀錄
- [ ] 使用網址前綴資源、`domain:` 層級、UTF-8 `.txt`
- [ ] 上傳後監測 4–8 週，不反覆修改
