## A. 策略與關鍵字研究

- **Cannibalization（關鍵字蠶食）**：同一查詢由自家多個 URL 互相競爭，導致排名不穩且訊號分散。→ 02
- **Commercial investigation intent（商業調查意圖）**：使用者在購買前比較、評估（best、review、vs）。→ 02
- **Competitor gap / Content gap（內容缺口）**：競爭者有排名而你沒有的關鍵字集合。→ 02
- **Content calendar（內容日曆）**：以週為單位排定主題、作者、發佈日與目標 URL 的計畫表。→ 02
- **Content hub / Topic cluster（內容樞紐 / 主題群）**：一個樞紐頁加多篇支撐頁、雙向內部連結的內容結構。→ 02、03
- **Content pruning（內容汰舊）**：合併、改寫或刪除零流量、過時或低品質頁面以提升整站品質。→ 02
- **CPC – Cost Per Click（每次點擊成本）**：廣告主為一次點擊付的價格；在關鍵字研究中代表商業價值的代理指標。→ 02
- **Evergreen content（長青內容）**：需求不隨時間明顯變動、可長期帶來流量的內容。→ 02、05
- **Expired domain（過期網域）**：原持有人未續約而被釋出的網域；Google 有 expired domain abuse 政策規範其濫用。→ 01、07
- **Head term（頭部關鍵字）**：1–2 字、搜尋量大、競爭高的廣泛關鍵字。→ 02
- **Informational intent（資訊意圖）**：使用者想了解、學習某件事。→ 02
- **Keyword clustering（關鍵字分群）**：依 SERP 重疊或語意把關鍵字合併成同一頁可承接的群組。→ 02
- **Keyword difficulty, KD（關鍵字難度）**：工具依前 10 名反向連結等估算的競爭難度分數（各工具定義不同，不可互比）。→ 02
- **Keyword master list（關鍵字母表）**：專案所有關鍵字與其意圖、分群、分數、目標 URL 的總表。→ 02
- **KPI – Key Performance Indicator（關鍵績效指標）**：衡量專案成敗的量化指標，如自然點擊、營收、已索引率。→ 01
- **Long-tail keyword（長尾關鍵字）**：字數較長、搜尋量低但意圖明確、合計佔總搜尋大宗的關鍵字。→ 02
- **Navigational intent（導航意圖）**：使用者想到特定網站或頁面（品牌名、login）。→ 02
- **Niche（利基）**：網站聚焦的特定主題市場。→ 01
- **Opportunity score（機會分數）**：搜尋量 × 難度 × 商業價值 × 意圖適配的優先順序評分。→ 02
- **Parent topic（上位主題）**：Ahrefs 用語，指一組關鍵字中搜尋量最大且 SERP 重疊的代表關鍵字。→ 02
- **People Also Ask, PAA（其他人也問了）**：SERP 中可展開的相關問題區塊，是長尾與 FAQ 來源。→ 02、21
- **Pillar page（樞紐頁 / 支柱頁）**：覆蓋主題全貌並連結所有子頁的頁面。→ 02、03
- **Risk register（風險登記表）**：列出專案風險、機率、影響、緩解與負責人的表格。→ 01
- **Sandbox（沙盒）**：坊間對新站排名延遲的稱呼；Google 否認有此機制，但新站需要時間累積訊號。→ 01
- **Search intent（搜尋意圖）**：使用者輸入查詢背後想達成的目的；以 SERP 實際結果判定。→ 02
- **Search volume（搜尋量）**：某關鍵字在特定市場的每月平均搜尋次數（估算值）。→ 02
- **Seasonality（季節性）**：搜尋需求隨年度週期變動的特性。→ 02
- **Seed keyword（種子關鍵字）**：關鍵字研究的起點詞，用來擴充出完整清單。→ 02
- **SERP – Search Engine Results Page（搜尋結果頁）**：搜尋引擎對一個查詢回傳的結果頁面。→ 02
- **SERP analysis（SERP 分析）**：記錄前 10 名的網域類型、格式、功能區塊以決定內容規格。→ 02
- **Site move（網站搬遷）**：Google 對換網域、改 URL 結構等重大變更的統稱。→ 14、04
- **Topical authority（主題權威）**：網站在某主題上因覆蓋深度與一致性而獲得的信任；非官方名詞但有實務效果。→ 02
- **Topic map（主題地圖）**：以 hub 與 spoke 組織的全站主題規劃圖。→ 02
- **Transactional intent（交易意圖）**：使用者準備購買或立即行動。→ 02
- **Zero-volume keyword（零搜尋量關鍵字）**：工具顯示 0–10 搜尋量，但可能有真實需求的關鍵字。→ 02

## B. 技術 SEO 與效能

- **AMP – Accelerated Mobile Pages**：Google 曾推動的行動頁面框架；2021 年起不再是 Top Stories 必要條件，**已不建議新專案採用**。→ 04
- **AVIF / WebP**：現代圖片格式，體積小於 JPEG / PNG，用於改善 LCP。→ 04
- **Brotli**：比 gzip 更高效的 HTTP 壓縮演算法。→ 04
- **Cache-Control**：HTTP 標頭，控制瀏覽器與 CDN 快取時間。→ 04
- **CDN – Content Delivery Network（內容傳遞網路）**：分散在全球的伺服器節點，就近回應使用者以降低延遲。→ 01、04
- **CLS – Cumulative Layout Shift（累積版面位移）**：Core Web Vitals 之一，量化頁面非預期位移；good ≤ 0.1。→ 04
- **Core Web Vitals, CWV（網站使用體驗核心指標）**：Google 定義的三個使用者體驗指標 LCP、INP、CLS，屬頁面體驗排名訊號。→ 04
- **CrUX – Chrome User Experience Report**：Chrome 使用者真實體驗資料集，是 CWV 的「實際資料」來源。→ 04、13
- **CSR – Client-Side Rendering（客戶端渲染）**：由瀏覽器執行 JS 產生內容，Googlebot 需二階段渲染。→ 04
- **DNS – Domain Name System**：把網域名稱解析為 IP 的系統；DNS 延遲影響 TTFB。→ 01、04
- **FCP – First Contentful Paint（首次內容繪製）**：第一個文字或圖片被繪製的時間；非 CWV，但為診斷指標。→ 04
- **FID – First Input Delay（首次輸入延遲）**：**已停用**，2024-03-12 由 INP 取代。→ 04
- **HSTS – HTTP Strict Transport Security**：強制瀏覽器只用 HTTPS 的安全標頭。→ 04
- **HTTP/2、HTTP/3**：較新的 HTTP 協定版本，支援多工與更低延遲（HTTP/3 基於 QUIC）。→ 04
- **HTTPS**：以 TLS 加密的 HTTP；Google 自 2014 年列為輕量排名訊號，實務上為必要條件。→ 04
- **Hydration（水合）**：前端框架在 SSR 輸出的 HTML 上掛載 JS 互動的過程；過重會拖累 INP。→ 04
- **INP – Interaction to Next Paint（互動到下一次繪製）**：CWV 互動性指標；good ≤ 200ms（web.dev，查閱 2026-11-03）。→ 04
- **ISR – Incremental Static Regeneration（增量靜態再生）**：Next.js 等框架在背景定期重建靜態頁面的機制。→ 15
- **JavaScript SEO**：確保依賴 JS 的內容能被 Googlebot 渲染與索引的技術實務。→ 04
- **Lazy loading（延遲載入）**：捲動到可視範圍才載入圖片 / iframe；首屏 LCP 元素不可延遲。→ 04
- **LCP – Largest Contentful Paint（最大內容繪製）**：CWV 載入指標；good ≤ 2.5s。→ 04
- **Lighthouse**：Google 開源的實驗室效能 / 可及性 / SEO 稽核工具。→ 13
- **Mobile-first indexing（行動優先索引）**：Google 以行動版內容作為索引與排名依據（2023 年起全面套用）。→ 04
- **Page experience（頁面體驗）**：Google 對 CWV、HTTPS、無侵入式插頁等體驗訊號的統稱。→ 04
- **PageSpeed Insights, PSI**：Google 工具，同時顯示 CrUX 實際資料與 Lighthouse 實驗室資料。→ 13
- **Preload / Preconnect / Prefetch**：資源提示（resource hints），提前載入關鍵資源或建立連線。→ 04
- **Render-blocking resources（阻塞渲染資源）**：阻止瀏覽器繪製的 CSS / JS，常見 LCP 瓶頸。→ 04
- **Responsive design（響應式設計）**：同一 HTML 依螢幕寬度調整版面；Google 建議的行動配置。→ 04
- **SSG – Static Site Generation（靜態網站生成）**：建置時預先產生 HTML。→ 15
- **SSR – Server-Side Rendering（伺服器端渲染）**：伺服器輸出完整 HTML，對爬蟲最友善。→ 04、15
- **Staging（測試環境）**：上線前的複製站；必須防止被索引。→ 14
- **TBT – Total Blocking Time（總阻塞時間）**：實驗室指標，用於代理 INP。→ 04
- **TTFB – Time to First Byte（首位元組時間）**：請求到收到第一個位元組的時間；建議 ≤ 800ms。→ 01、04
- **TLS / SSL 憑證**：啟用 HTTPS 的憑證；Let's Encrypt 免費。→ 04
- **WebPageTest**：可選測試節點與連線條件的效能測試工具。→ 13
- **X-Robots-Tag**：在 HTTP 標頭中設定索引指令（如 noindex），適用於 PDF 等非 HTML 檔。→ 04

## C. 爬取與索引

- **Canonical / rel="canonical"（標準網址）**：告訴 Google 多個相似 URL 中哪個是主要版本。→ 04
- **Crawl budget（爬取預算）**：Googlebot 願意且能夠在網站上爬取的 URL 數量；大型網站才需關注。→ 04
- **Crawl depth / Click depth（點擊深度）**：從首頁到某頁所需的最少點擊數；建議 ≤ 3。→ 03
- **Crawled – currently not indexed（已檢索，目前尚未建立索引）**：Search Console 狀態，Google 爬了但決定不索引，常見於品質或重複問題。→ 04、12
- **Discovered – currently not indexed（已找到，目前尚未建立索引）**：Google 知道 URL 但尚未爬取，常見於新站或爬取預算不足。→ 04、12
- **Faceted navigation（分面導覽）**：電商篩選（顏色、尺寸、價格）產生大量 URL 組合的導覽方式。→ 19
- **Googlebot**：Google 的網頁爬蟲；分桌面與智慧型手機版本。→ 04
- **Google-Extended**：robots.txt 中的使用者代理代號，用於控制內容是否用於 Gemini 等 AI 模型訓練（不影響搜尋索引）。→ 08
- **Index（索引）**：Google 儲存並可供檢索的頁面資料庫。→ 04
- **Index bloat（索引膨脹）**：大量低價值 URL（參數、標籤、分頁）被索引。→ 04
- **Indexing API**：Google 提供的即時索引 API，官方僅限 JobPosting 與 BroadcastEvent 頁面。→ 04
- **Log file analysis（記錄檔分析）**：分析伺服器日誌中 Googlebot 的實際爬取行為。→ 04、13
- **Noindex**：meta robots 或 X-Robots-Tag 指令，要求不索引該頁。→ 04
- **Nofollow / rel="nofollow"**：連結屬性，提示 Google 不要把該連結視為背書；2019 年起為「提示」而非指令。→ 16
- **Orphan page（孤立頁）**：沒有任何內部連結指向的頁面。→ 03
- **Pagination（分頁）**：長清單分成多頁；rel=prev/next **已不被 Google 使用**（2019 年宣布），改以自我 canonical 與可爬連結處理。→ 03、04
- **Redirect chain（重導向鏈）**：A → B → C 的多跳重導向，浪費爬取並損失訊號。→ 04
- **Rendering（渲染）**：Googlebot 執行 JS 產生最終 DOM 的過程（Web Rendering Service）。→ 04
- **robots.txt**：告知爬蟲可 / 不可爬取路徑的檔案；不能用於阻止索引。→ 04
- **Robots meta tag**：頁面 `<head>` 中的 index / noindex / follow / nofollow 指令。→ 04
- **Sitemap（XML sitemap / 網站地圖）**：列出可索引 URL 的 XML 檔，協助發現。→ 04
- **Soft 404**：頁面顯示「找不到」但回傳 200 狀態碼。→ 04、12
- **Status code（HTTP 狀態碼）**：200 正常、301 永久移轉、302 暫時、404 找不到、410 已永久移除、5xx 伺服器錯誤。→ 04
- **URL Inspection tool（網址檢查工具）**：Search Console 中查看單一 URL 索引狀態、渲染結果、請求索引的工具。→ 13
- **URL parameters（網址參數）**：`?sort=price` 等查詢字串；Search Console 的 URL 參數工具**已於 2022 年停用**。→ 04

## D. 頁面與內容

- **Above the fold（首屏）**：不捲動即可見的區域；廣告過多會違反政策並影響體驗。→ 05、09
- **Alt text（替代文字）**：圖片的文字描述，供無障礙與圖片搜尋使用。→ 05
- **Anchor text（錨文字）**：超連結上可點擊的文字。→ 05、16
- **Author page（作者頁）**：展示作者姓名、資歷、作品的頁面，支持 E-E-A-T。→ 05、07
- **Boilerplate（樣板內容）**：頁首、頁尾、側欄等每頁重複的區塊。→ 05
- **Breadcrumb（麵包屑）**：顯示頁面層級位置的導覽列，可搭配結構化資料。→ 03、06
- **Content decay（內容衰退）**：頁面流量隨時間自然下滑的現象。→ 02
- **Content freshness（內容新鮮度）**：對時效性查詢，Google 偏好較新或最近更新的內容（Query Deserves Freshness）。→ 20
- **Duplicate content（重複內容）**：多個 URL 內容相同或高度相似；不是處罰但會分散訊號。→ 04、05
- **E-E-A-T – Experience, Expertise, Authoritativeness, Trustworthiness（經驗、專業、權威、可信）**：Google 品質評分者指南中的品質概念，Trust 為核心。→ 07
- **Featured snippet（精選摘要）**：SERP 頂部直接摘錄某頁內容回答的區塊（「位置 0」）；2026 年仍存在，AIO 無法產生時會退回精選摘要。→ 05、21
- **First-hand experience（第一手經驗）**：作者親身使用、測試、到訪後的描述，是 E-E-A-T 中 Experience 的證據。→ 05、07
- **H1 / H2 / H3（標題標籤）**：HTML 標題層級，表達內容結構。→ 05
- **Internal linking（內部連結）**：同一網站頁面間的連結，傳遞訊號並建立結構。→ 03
- **Keyword stuffing（關鍵字堆砌）**：過度重複關鍵字，屬垃圾內容政策違規。→ 07
- **Meta description（中繼描述）**：頁面摘要標籤；非排名因素，但影響 CTR。→ 05
- **People-first content（以人為本的內容）**：Google helpful content 指南的核心原則：為使用者而非搜尋引擎創作。→ 05、07
- **Readability（可讀性）**：內容易於閱讀與掃讀的程度。→ 05
- **Thin content（薄內容）**：缺乏實質價值、字數少或自動生成的頁面。→ 05、07
- **Title tag / Title link（標題標籤 / 標題連結）**：`<title>` 元素；Google 顯示的「標題連結」可能被改寫。→ 05
- **UGC – User-Generated Content（使用者生成內容）**：評論、留言、論壇貼文；需防垃圾並用 rel="ugc"。→ 05、07
- **YMYL – Your Money or Your Life**：影響健康、財務、安全、社會福祉的主題，Google 對其品質要求最高。→ 07

## E. 連結與權威

- **Backlink / Inbound link（反向連結）**：其他網站指向你的連結。→ 16
- **Brand mention（品牌提及）**：未加連結的品牌名稱提及；可能作為實體訊號。→ 16
- **Broken link building（失效連結建設）**：找出他站失效外連並提供替代內容的連結策略。→ 16
- **Digital PR（數位公關）**：以原創資料、故事取得媒體報導與連結。→ 16
- **Disavow（拒絕連結）**：透過 Search Console 工具要求 Google 忽略特定連結；Google 表示多數網站不需要使用。→ 16
- **Domain Rating, DR / Domain Authority, DA / Authority Score, AS**：Ahrefs / Moz / Semrush 各自的網域連結強度指標；非 Google 指標。→ 16
- **Dofollow**：非正式用語，指未加 nofollow 的一般連結。→ 16
- **Guest post（客座文章）**：在他站發表文章並取得連結；大規模換連結屬 link spam。→ 16
- **Link equity / Link juice（連結權重）**：連結傳遞的排名價值（PageRank 的通俗說法）。→ 16
- **Link spam（連結垃圾）**：買賣、交換、自動化等操縱連結的行為，屬 spam policies 違規。→ 07、16
- **Link velocity（連結成長速度）**：單位時間新增反向連結的數量。→ 16
- **PageRank**：Google 以連結計算頁面重要性的原始演算法；仍是排名系統的一部分，但公開分數已停用。→ 16
- **PBN – Private Blog Network（私人部落格網路）**：為操縱連結而建立的網站群，屬違規。→ 16
- **Referring domain（參照網域）**：至少有一個連結指向你的獨立網域數。→ 16
- **rel="sponsored"**：標示付費 / 聯盟連結的屬性。→ 09、16
- **rel="ugc"**：標示使用者生成內容中的連結。→ 16
- **Toxic link（毒性連結）**：工具判定可能有害的連結；Google 表示其系統會自動忽略多數垃圾連結。→ 16
- **Unlinked mention（未連結提及）**：品牌被提及但未加連結，可爭取補連結。→ 16

## F. 結構化資料

- **Article schema**：新聞 / 部落格文章的結構化資料類型。→ 06
- **BreadcrumbList**：麵包屑的結構化資料類型。→ 06
- **FAQPage schema**：FAQ 結構化資料；**已停用**：2023-08 起僅限政府與健康權威網站，2026-05 起完全不顯示 FAQ rich result。→ 06

- **Knowledge Graph / Knowledge Panel（知識圖譜 / 知識面板）**：Google 的實體資料庫與 SERP 右側實體資訊卡。→ 06、16
- **LocalBusiness schema**：本地商家的結構化資料類型（含 NAP、營業時間）。→ 06、17
- **Organization schema**：組織實體資料（名稱、logo、社群連結），支持品牌實體識別。→ 06

- **Rich result（複合式搜尋結果）**：SERP 中含評分、價格、FAQ 等額外資訊的結果。→ 06

- **Schema.org**：結構化資料詞彙的共同標準。→ 06
- **Sitelinks（網站連結）**：SERP 中品牌結果下方的子頁面連結，由 Google 自動產生。→ 03
- **Structured data（結構化資料）**：以標準格式標註頁面內容意義，幫助 Google 理解。→ 06
- **VideoObject schema**：影片結構化資料；2026-09 新增 creator 屬性與 interactionStatistic 類型文件（Google 文件更新紀錄）。→ 06

## G. 演算法、品質與政策

- **Core update（核心更新）**：Google 對核心排名系統的廣泛更新，每年數次；2026 年已有 3 月、5 月兩次（查閱 2026-11-03）。→ 07
- **Discover**：Google 的個人化內容推薦流；2026-02 有專屬 Discover 更新。→ 20
- **Doorway abuse（入口頁濫用）**：為特定查詢建立大量引導至同一目的的頁面，屬違規。→ 07
- **Expired domain abuse（過期網域濫用）**：2024-03 新增政策：購買過期網域以低價值內容操縱排名。→ 01、07
- **Helpful content system（實用內容系統）**：2022 推出的網站層級訊號；**已變更**：2024-03 併入核心排名系統，不再是獨立系統。→ 07
- **Manual action（專人介入處理 / 手動處置）**：Google 人工審查後對違規網站施加的處罰，在 Search Console 可見並可申請重審。→ 07、12
- **Panda / Penguin**：歷史演算法（2011 / 2012），分別針對內容品質與連結垃圾；**已併入核心系統**，現僅作歷史名詞。→ 07
- **Query Deserves Freshness, QDF（需要新鮮度的查詢）**：Google 對時效性查詢偏好新內容的機制。→ 20
- **Quality Rater Guidelines, QRG（品質評分者指南）**：Google 給外部評分者的文件，定義 E-E-A-T、YMYL、Needs Met；最新版 2025-09-11（官方 PDF：https://static.googleusercontent.com/media/guidelines.raterhub.com/en//searchqualityevaluatorguidelines.pdf ，查閱 2026-11-03）。→ 07
- **RankBrain / BERT / MUM**：Google 的機器學習排名與理解系統名稱；屬核心系統組成，SEO 無法針對單一系統優化。→ 07
- **Reconsideration request（重審要求）**：修正違規後向 Google 申請移除手動處置。→ 07、12
- **Reviews system（評論系統）**：針對評測類內容品質的排名系統（原 Product Reviews Update，2023 年擴展至所有評論）。→ 07
- **Scaled content abuse（大規模內容濫用）**：2024-03 新增政策：以 AI、抓取、拼接等方式大量產生無價值頁面。→ 07、11
- **Search Status Dashboard（搜尋狀態資訊主頁）**：Google 公告排名更新與中斷事件的官方頁面。→ 07、13
- **Site reputation abuse（網站信譽濫用）**：2024-03 新增政策：第三方內容借用主站信譽排名（俗稱 parasite SEO）；2026-08 在 EEA 調整為「分開歸類」而非手動處置。→ 07
- **Spam update（垃圾內容更新）**：針對 spam policies 執行的更新；2026 年已有 3、6、8、9 月四次。→ 07
- **SpamBrain**：Google 的 AI 垃圾內容偵測系統。→ 07
- **Thin affiliation（薄聯盟內容）**：只轉貼商家描述、無加值的聯盟頁面，屬違規。→ 07、09

## H. AI 搜尋與 SERP 功能

- **AEO – Answer Engine Optimization（答案引擎優化）**：針對直接回答型版位與引擎（精選摘要、PAA、AI Overviews、語音助理、聊天型答案引擎）的優化；Google 2026-05 指南視 AEO / GEO 為 SEO 的一部分。→ 21、08
- **AI Assistant channel（GA4 AI 助理管道）**：GA4 預設管道群組 2026 新增的管道，medium 為 `ai-assistant`（referrer 符合 AI 助理清單時自動設定，只有 UTM 不保證進此管道），涵蓋 ChatGPT、Gemini、Deepseek、Copilot、Grok 等聊天工具，不含 AI Overviews / AI Mode（仍算 Organic Search）。→ 21、13
- **AI Mode（AI 模式）**：Google 搜尋的全 AI 對話式介面分頁，2025 年推出並陸續擴展市場。→ 08
- **AI Overviews（AI 摘要）**：SERP 頂部由 Gemini 生成的摘要，附引用來源。→ 08
- **Answer block（答案區塊）**：緊接在問題式標題之後、可單獨成立的 40–120 字答案段落、清單或表格。→ 21
- **Brand recommendation testing（品牌推薦查詢測試）**：用固定提示集定期測試品牌在答案引擎中的提及率與描述正確率。→ 21
- **Citation（引用）**：AI 回答中列出的來源連結；AI 搜尋可見度的主要指標。→ 08
- **Discussions and forums（討論與論壇）**：Google SERP 區塊，突顯 Reddit 等論壇內容。→ 02、05
- **Generative AI performance report（生成式 AI 成效報表）**：Search Console 2026-06 以 beta 推出、2026-08-31 起全球可用的報表，顯示 AI Overviews / AI Mode 曝光。→ 08、13
- **GEO – Generative Engine Optimization（生成式引擎優化）**：讓內容被 ChatGPT、Gemini、Perplexity 等生成式引擎引用的優化。→ 08
- **Grounding（接地）**：LLM 以即時搜尋結果作為回答依據的機制。→ 08
- **Grounding queries（接地查詢）**：Bing Webmaster Tools AI Performance 提供的抽樣片語，是 AI 檢索本站內容時用的查詢。→ 21、13
- **Knowledge cutoff（知識截止）**：LLM 訓練資料的時間上限。→ 08
- **LLM – Large Language Model（大型語言模型）**：生成式 AI 的基礎模型（Gemini、GPT、Claude）。→ 08
- **llms.txt**：社群提案的檔案，供 LLM 讀取網站摘要；**非 Google 官方標準，Google 表示不使用**。→ 08
- **nosnippet / data-nosnippet / max-snippet**：控制 Google 摘要（含 AI Overviews 引用片段）的指令。→ 08
- **Preferred sources（偏好來源）**：Google 允許使用者將網站設為偏好來源的功能，用於 Top Stories，也會在 AI Overviews / AI Mode 顯示「preferred」標章；只限網域或子網域層級，AIO / AI Mode 部分需在 GSC 保持納入生成式 AI 功能；2026-08 文件新增自訂按鈕做法。→ 20
- **Question master list（問題母表）**：依主題群集整理使用者問題、語言變體、來源與處理方式的清單。→ 21
- **Read more deep link（「閱讀更多」深連結）**：摘要中跳到頁面指定段落的連結；內容必須立即可見，不可藏在 tab 裡。→ 21
- **Search profile badge（搜尋個人檔案徽章）**：2026-09 Google 文件新增的網站徽章功能。→ 08
- **Speakable**：beta 結構化資料，只限美國、英文設定的 Google Home 裝置與新聞查詢。→ 06、21
- **Zero-click search（零點擊搜尋）**：使用者在 SERP 直接獲得答案而不點擊任何結果。→ 08

## I. 變現、廣告與分析

- **Ad Exchange, AdX**：Google 的程序化廣告交易平台，透過 Google Ad Manager 或聯播網（Mediavine、Raptive）接入。→ 09
- **Ad intents（意圖廣告）**：Auto ads 在內文產生 links / anchors / chips 的格式，點擊開啟含廣告與 Gemini 生成內容的對話框。→ 22
- **AdSense Auto ads（自動廣告）**：由 Google 自動決定版位的廣告模式。→ 22、09
- **AdSense**：Google 的發布商廣告計畫；無官方流量門檻，付款門檻 USD 100。→ 22、09
- **Ad serving at risk（放送有風險）**：AdSense 政策中心尚未執行的警告，附執行日期。→ 22
- **Ad serving limits（廣告放送限制）**：Google 評估流量品質期間限制帳號可放送的廣告數，通常少於 30 天、自動解除。→ 22
- **ads.txt / app-ads.txt**：IAB 標準檔案，宣告哪些賣方被授權販售你的廣告庫存。→ 22、09
- **Affiliate marketing（聯盟行銷）**：推廣他人產品並依成效（點擊 / 成交）獲得佣金。→ 09
- **Arbitrage（流量套利）**：買流量導到廣告多於內容的頁面賺差價；AdSense 與 Google Ads 政策皆不允許。→ 22、23
- **Attribution（歸因）**：把轉換歸功於哪個管道 / 接觸點的模型。→ 13
- **Bounce rate / Engagement rate（跳出率 / 互動率）**：GA4 以互動率（有互動的工作階段比例）取代舊版跳出率。→ 13
- **CMP – Consent Management Platform（同意管理平台）**：Cookie 同意工具；EEA / UK / 瑞士流量需使用 Google 認證 CMP（2024 起）。→ 22、09
- **Confirmed Click（確認點擊）**：Google 對易誤點廣告加上的第二次點擊步驟。→ 22
- **Consent Mode（同意聲明模式）**：把使用者的同意狀態傳給 Google 標記，分 Basic 與 Advanced 兩種；EEA / UK / 瑞士流量必須。→ 22、23、15
- **Conversion rate（轉換率）**：完成目標行動（購買、註冊、來電）的比例。→ 13、19
- **CPM / eCPM（每千次曝光成本 / 有效每千次曝光收益）**：廣告每千次曝光的價格 / 收益。→ 09
- **CTR – Click-Through Rate（點閱率）**：點擊 ÷ 曝光；在 Search Console 與廣告中意義不同。→ 13
- **EPMV / Session RPM（每千工作階段收益）**：Ezoic、Mediavine 等以工作階段計算的收益指標。→ 09
- **Ezoic**：聯播網；2026-02 起新發布商門檻提高至 250,000+ 月活躍使用者（第三方報導，待官方確認）。→ 09
- **GA4 – Google Analytics 4**：Google 現行分析平台；Universal Analytics **已於 2023–2024 停用**。→ 13
- **Google Ad Manager, GAM**：Google 的廣告伺服器平台，中大型發布商使用。→ 09
- **Google Search Console, GSC**：Google 免費工具，提供曝光、點擊、索引、CWV、手動處置等資料；保留 16 個月。→ 13
- **Google Tag Manager, GTM**：管理追蹤碼的容器工具。→ 13
- **GPP – Global Privacy Platform（全球隱私協定）**：IAB 的美國各州隱私訊號標準，AdSense 讀取 US National 等字串。→ 22
- **Impression（曝光）**：Search Console 中頁面出現在使用者搜尋結果的次數；廣告中為廣告顯示次數。→ 13
- **Invalid traffic, IVT（無效流量）**：機器人、誤點、自點等不應計費的流量；導致 AdSense 停權的主因之一。→ 22、09
- **Journey by Mediavine**：Mediavine 的入門聯播網；門檻 30 天 ≥ 1,000 Tier 1 國家 sessions（查閱 2026-11-03）。→ 09
- **Mediavine**：高階聯播網；2026 年起門檻改為年廣告收入 ≥ USD 5,000。→ 09
- **Offerwall（內容牆）**：使用者看獎勵廣告換取存取權的 Privacy & messaging 訊息。→ 22
- **Organic traffic（自然流量）**：來自未付費搜尋結果的流量。→ 13
- **Pageview, PV（瀏覽量）**：頁面被載入的次數；聯播網門檻常以此計。→ 09、13
- **Payment hold（付款暫停）**：因驗證、稅務、付款方式等未完成而暫停當月付款。→ 22
- **Policy center（政策中心）**：AdSense 列出政策問題、法規問題與廣告主偏好的後台頁面。→ 22
- **Programmatic advertising（程序化廣告）**：以自動化競價買賣廣告曝光。→ 09
- **Publisher Restrictions（發布商限制）**：可放 AdSense 但需求受限的內容類別（線上賭博、酒類等）；線上賭博限制對美國、英國等 18 國使用者不適用。→ 22
- **Raptive（原 AdThrive）**：高階聯播網；2025-10 起門檻降為 25,000 月瀏覽量並含地域比例要求。→ 09
- **RDP – Restricted Data Processing（限制資料處理）**：使用者退出後 Google 只做有限資料處理的模式。→ 22
- **Restricted ad serving（限制放送）**：只有部分廣告來源能出價的處置狀態。→ 22
- **RPM – Revenue Per Mille（每千次收益）**：每 1,000 次曝光或瀏覽的收益；Page RPM 與 Session RPM 需區分。→ 09
- **sellers.json（賣方資訊檔）**：公開廣告賣方身分的 IAB 標準，AdSense 可選 Confidential / Transparent。→ 22
- **Sensitive categories（敏感類別）**：AdSense 封鎖控制中的廣告類別，Restricted 類（賭博、酒精）預設封鎖。→ 22
- **Session（工作階段）**：GA4 中一段使用者互動期間（預設 30 分鐘無活動結束）。→ 13
- **TCF v2.3（IAB 透明與同意框架 2.3 版）**：2026-03-01 起 AdSense 對 EEA / UK / 瑞士要求的同意字串版本。→ 22
- **Tier 1 countries（一線國家）**：廣告單價最高的國家（美、加、英、澳、紐等），聯播網門檻的計算基礎。→ 09
- **UTM parameters（UTM 參數）**：標記流量來源的 URL 參數（utm_source 等）。→ 13
- **Valuable inventory policy（有價值的廣告空間政策）**：AdSense 政策，禁止在無內容、低價值或複製內容頁面放廣告；現行官方名稱為 Inventory value（廣告空間價值），屬 Publisher Policies 的行為政策。→ 22
- **Viewability（可視度）**：廣告有 ≥ 50% 像素顯示 ≥ 1 秒的比例（IAB 標準）。→ 09
- **Vignette ads（插頁廣告）**：頁面之間的全螢幕 overlay 廣告，觸發條件可在 advanced settings 調整。→ 22
- **W-8BEN（外國個人美國稅務表）**：符合條件的非美國個人向 Google 申報稅務身分、主張協定優惠用的表單（實體用 W-8BEN-E，美國人士用 W-9，由後台稅務問題判定）。→ 22

## J. 付費搜尋（Google Ads）

- **AdsBot（Google Ads 審查爬蟲）**：Google Ads 檢查到達頁品質的爬蟲，會忽略 robots.txt 中 `*` 的規則，要擋必須點名。→ 23
- **Ad strength（廣告強度）**：RSA 撰寫時的評等，不影響放送資格與 Ad Rank。→ 23
- **Advertiser verification（廣告主驗證）**：Google 要求廣告主證明身分或業務運作；有期限的驗證不能延長，逾期帳號暫停。→ 23
- **AI Max for Search（AI Max）**：Search 活動的一組 AI 設定，包含搜尋字詞比對、文字自訂、最終網址擴展。→ 23
- **Circumventing systems（規避系統）**：嚴重違規政策，包括 cloaking、停權後開新帳號等；偵測即停權。→ 23
- **Data Manager（資料管理工具）**：Google Ads 的第一方資料與離線轉換匯入介面；2026-06-15 起是離線轉換上傳的主要 API 路徑（Google Ads API 不收新使用者，既有存取依 token 判定）。→ 23
- **Demand Gen（需求開發活動）**：涵蓋 YouTube、Discover、Gmail 與多媒體聯播網的活動類型，已取代 Video action campaigns。→ 23
- **Destination requirements（到達網頁規定）**：要求到達頁可用、與廣告一致、內容原創。→ 23
- **Eligible (limited)（符合資格，受限）**：因政策限制，廣告只在部分地點、年齡或裝置放送。→ 23
- **Enhanced conversions（強化轉換）**：用雜湊處理的第一方資料提高轉換比對；2026 年起網站與潛在客戶合併為單一開關。→ 23
- **Limited ad serving（限制廣告放送）**：對「未合格廣告主」在特定情境限制曝光的政策。→ 23
- **Manager account / MCC（管理員帳戶）**：用來管理多個 Google Ads 帳號的上層帳戶。→ 23
- **Optimization score（最佳化分數）**：Google 估計帳戶潛力的 0–100% 分數，不是 KPI。→ 23
- **Performance Max / PMax（最高成效廣告活動）**：跨所有 Google 版位、以目標為導向的自動化活動。→ 23、19
- **Policy manager（政策管理員）**：查看拒登、受限與申訴紀錄的工具。→ 23
- **Quality Score（品質分數）**：關鍵字層級 1–10 分的診斷工具，不是競價輸入值。→ 23
- **Responsive search ad / RSA（回應式搜尋廣告）**：最多 15 則標題、4 則說明，由系統自動組合。→ 23
- **Smart Bidding（智慧出價）**：Max conversions、tCPA、tROAS 等以轉換為目標的自動出價。→ 23
- **Strike system（三振制度）**：特定政策的警告、暫停 3 天、暫停 7 天、停權四段處置；振數保留 90 天，申訴成功則移除。→ 23

## 補充：其他常用名詞

- **Black hat / White hat / Grey hat SEO（黑帽 / 白帽 / 灰帽）**：違規操縱 / 符合指南 / 介於兩者之間的手法。→ 07
- **ccTLD – Country Code Top-Level Domain（國家代碼頂級網域）**：.tw、.jp 等，為強烈地理定向訊號。→ 01、10
- **gTLD – Generic Top-Level Domain（通用頂級網域）**：.com、.org、.app 等，無地理定向。→ 01
- **Geo-targeting（地理定向）**：讓內容針對特定國家使用者；GSC 已無此設定（International Targeting 報表已停用、國家定向不再支援；support.google.com/webmasters/answer/6059209，查閱 2026-11-03），地理定位靠 ccTLD、hreflang 與在地訊號（在地地址／電話、語言與幣別、在地連結；developers.google.com/search/docs/specialty/international/managing-multi-regional-sites）。→ 10
- **Google Business Profile, GBP（Google 商家檔案）**：本地商家在 Google 地圖與搜尋的檔案（原 Google My Business）。→ 17
- **Google Domains**：**已停用**，2023 年售予 Squarespace。→ 01
- **hreflang**：標示頁面語言 / 地區版本的屬性，用於多語言站。→ 10
- **Local pack / Map pack（本地包）**：SERP 中的地圖 + 三家商家區塊。→ 17
- **NAP – Name, Address, Phone**：本地 SEO 中商家名稱、地址、電話的一致性。→ 17
- **Programmatic SEO, pSEO（程序化 SEO）**：以模板與資料集批量產生頁面；需避免 scaled content abuse。→ 11
- **Subdomain / Subdirectory（子網域 / 子目錄）**：blog.example.com vs example.com/blog/；Google 表示皆可，但子目錄更容易共享網站訊號。→ 03、10
- **x-default**：hreflang 中的預設 / 語言選擇頁標記。→ 10
