# start：新專案啟動

目標：30 分鐘內讓專案有啟動表、閱讀路徑與前兩週行動，依 KB 00 §1 的流程。

## 步驟

1. 弄清楚三件事，缺的直接問：專案類型（內容站 / 流量站、電商、企業官網 / SaaS、本地商家、新聞 / 時效型，可複選）、目標市場與語言（含混語）、變現模式。
2. 讀 KB：
   ```bash
   python3 "<SKILL_DIR>/scripts/kb_lookup.py" --section "00 1"      # 30 分鐘啟動流程
   python3 "<SKILL_DIR>/scripts/kb_lookup.py" --section "00 2"      # 依專案類型的閱讀路徑（含「南亞 / 東南亞新市場」疊加）
   python3 "<SKILL_DIR>/scripts/kb_lookup.py" --section "00 3"      # 鐵律 32 條，挑與本專案相關的 8–10 條列給使用者
   ```
   市場是台灣時，再讀 `--section "24 3"` 與 `--section "24 6"`。其他市場讀 `--section "25 1"` 與 `--section "25 2"`，先確認主要語言在 AdSense 支援清單。
3. 複製啟動表到專案資料夾：`cp "<SKILL_DIR>/references/kb/_templates/專案啟動表.md" "<專案資料夾>/<專案名>-啟動表.md"`，把已知資訊填進去，不確定的格寫「待確認：原因」。
4. 依 00 §2 的路徑，列出這個專案「至少要讀」的小節清單（章 §小節 + 一句為什麼），不要列整章。
5. 給前兩週行動清單（10 項內），每項附章節；流量站預設包含：網域與結構決策（01 §5、10 §1）、主題地圖（02）、技術基線（04 §2–§5、§11）、內容模板與 E-E-A-T 頁（05 §13、F6）、追蹤安裝（13）、AdSense 前置（22 §1、14 §I）。

## 輸出格式

```
## <專案名> 啟動摘要
- 類型 / 市場 / 語言 / 變現：…
- 語言合規：…（22 §1.1）
- 風險紅線：…（07 §4；台灣看 24 §6，其他市場看 25 §6）
## 至少要讀的小節
| 章 §小節 | 為什麼 |
## 前兩週行動
| # | 行動 | 章節 | 驗收 |
## 啟動表
已建立 <路徑>，待確認欄位：…
```
